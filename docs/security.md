# 数据与凭据

## 上传内容

仓库只包含源码、模型模板、示例配置、测试、工作流 Skill 和脱敏验证摘要。不包含实际网关地址、账号登录文件、GPT 模型缓存、本地路由密钥、LaunchAgent、聊天记录、原始请求日志或个人工作目录。

`router.local.json`、`.env`、密钥、日志与运行目录由 `.gitignore` 排除。`scripts/check_release.py` 检查跟踪文件与常见敏感模式，但不能替代对新增文件的人工审查。

## 运行时

- 路由仅绑定 `127.0.0.1`，不对局域网开放。POST 与活动请求查询需要随机本地 token；健康检查不含个人信息。
- GPT 使用调用端已提供的认证头，目的地固定；GLM / DeepSeek 用请求头白名单重建，不继承 OpenAI Authorization、Cookie、账号或会话字段。
- 外部网关需要 key 时，只能明确指定环境变量。安装器将选中的变量写入本机 LaunchAgent，文件模式为 `0600`；这属于本机明文存储，不是 Keychain。不要共享 plist、配置备份或安装目录。
- 路由拒绝重定向，保留 TLS 校验。HTTP 网关仍可用于原公司接入形式，但其链路不提供 HTTPS 加密。
- 日志仅记录路由、模型、HTTP 状态、推理强度、时间和错误类型，不记录提示词、响应正文或密钥。HTTP 状态不能代替完整任务成功状态。
- 切换到 GLM 或 DeepSeek 时，当前可见历史与工具输出也可能进入其请求。应仅把允许发送给所选网关的内容放入该聊天。

## 不覆盖的威胁模型

同一用户下的其他本机进程可能读取其私有文件。loopback token 和工作流 UUID 登记不构成对同用户恶意进程的隔离。路由不重新实现 Codex 的执行权限系统，也不代表网关支持 OpenAI 全部 Responses、搜索、语音或多模态功能。
