## 本次整合做出的改动

- 在最终 router 与 tool-search adapter 的基础上，将公司 URL 从源码移出，放入私有配置；提供占位示例和可选独立网关 key。
- 保留 GPT 固定上游与认证隔离，统一默认端口 17864；增加活动请求查询、JSON 对象校验与转发完成标记。
- 将第一段便携安装思路与第三段“保留后来设置”的恢复要求合成新的 `manage.py`，采用独立目标目录和服务标签，不沿用旧机器 manifest。
- 生成模型目录时只取接收者自己的 GPT 条目，再加入两个外部模型模板；不打包 GPT 缓存及其提示词。
- 保留第二段 Skill 的全部代码、参考说明与 66 项测试；把它作为可选层，独立于工具发现适配。
- 增加本地 HTTP 模拟上游、安装/恢复事务、开关回滚、凭据和发布文件检查；附上 CI 定义。

## 被后续结论取代的内容

1. 旧版 DeepSeek 128K / 90% 是临时本地预算，最终目录为 1M / 95%。
2. 网关返回 200 不等于按需工具发现成功。后续只有完整发现、执行及结果校验才算通过。
3. 单看菜单名称、模型缓存或精简 CLI 测试，不能证明完整桌面长任务兼容。
4. GPT 使用的 Responses Lite 与外部模型标准 Responses 不应套用同一组协议字段断言。历史通用探针对 GPT 的原始失败记录没有被改写；另以实际调用与正确返回结果给出功能回归结论。
5. 手机 DeepSeek 路由仍未解决，不纳入已支持范围。

## 原文件未直接搬入的原因

第一段旧 ZIP 只包含 GPT / GLM。第三段 `manage_tool_search.py` 和 `restore_default_route.py` 对应特定机器、服务名称与备份路径。把它们和旧 manifest 原封不动拼在一起会得到互相冲突的安装器。本项目保留其能力和测试目标，统一为新安装的可移植生命周期；原本部署保持不变。
